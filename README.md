# IT412-Final_Project

Simple Anime Watchlist Tracker

Quick start

1. Install dependencies:

```bash
npm install
```

2. Run the server:

```bash
npm start
```

3. Open http://localhost:3000 in your browser and manage your watchlist.

Note: This version stores data in your browser's `localStorage` and does not include a backend API. You can also open `public/index.html` directly in a browser for local usage.
